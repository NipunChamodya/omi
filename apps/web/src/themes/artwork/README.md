# Card-back artwork

These two SVGs are original geometric vector artwork authored for OMI Stage I. No external images, fonts, scripts, links or embedded user data are included. `classic-back.svg` uses emerald diamond filigree; `royal-back.svg` uses a gold crown and nested midnight diamonds. Both use a 100 × 140 viewBox.

Card identities remain the existing shared Card values. Faces use CSS and Unicode suit symbols, with the rank/suit text kept in the card component. Registry entries reference trusted local assets; adding a design must never change ranks, suits, actions, scores or hidden-card projections. No additional license for the whole application is introduced by this directory.
