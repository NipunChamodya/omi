# OMI original social audio

`emerald-v1.mp3`, `coast-v1.mp3`, `tap-v1.wav`, `chime-v1.wav` and `chuckle-v1.wav` are original deterministic synthetic compositions/effects generated for OMI by `infra/scripts/generate-social-audio.py`. No recordings, sampled instruments, traditional-song melodies, external tracks or user audio were used.

These assets and the generation script are dedicated to the public domain under **CC0 1.0 Universal** (SPDX: CC0-1.0). No attribution is required. This dedication covers only these new audio assets/generator, not the application's other code/artwork.

License text: https://creativecommons.org/publicdomain/zero/1.0/legalcode

Regenerate with Python 3, FFmpeg/libmp3lame and ffprobe. Runtime hosting/browser playback does not require those tools. Assets are loaded only after local audio opt-in; no music recording/upload feature exists.
